
Tutor-Parent Communication Platform

1. Scope 
A privacy-first, web-based communication and management platform for independent, small-scale tutors, replacing WhatsApp groups and paid institute-grade CRM (Customer Relationship Management) tools. The platform allows a tutor to manage batches, mark attendance, share notes, track student progress, and communicate privately with students and parents — without ever exposing any user's personal phone number to another user.
1.2 In Scope (v1)
Single-tutor platform (one tutor per deployment; not multi-tenant)
Web application, mobile-responsive
Email + password authentication with invite-link-based onboarding
Batch and subject management with recurring schedules and auto-generated sessions
Per-student, per-session attendance tracking with edit/correction support
Structured communication: one-way notice board + private tutor↔parent and tutor↔student chat
File/note sharing per batch
Progress tracking with structured scores + remarks
Light analytics: attendance percentage, score-over-time table/simple graph, recent remarks feed
In-app notifications (configurable by event type)
Cross-batch, per-child parent dashboard
1.3 Objectives
Eliminate phone number exposure between tutor, students, and parents.
Replace WhatsApp as the primary communication channel for tuition-related updates.
Digitize attendance and progress tracking currently done manually (notebooks) or not at all.
Give parents visibility into their child's tuition activity without needing to ask the tutor directly.
Lay a data foundation (structured scores/topics) that supports rich analytics in v2 without rework.

2.1 Tutor (Admin) Requirements
Register and log in using email and password.
Create, edit, and manage subjects.
Create batches by assigning a subject and schedule.
Edit batch schedules with confirmation before affecting future sessions.
Generate single-use, time-expiring invite links for students and parents.
Remove or deactivate students from a batch while archiving their data.
Mark specific dates as holidays or no-class days for a batch.
Mark, edit, or delete attendance records for individual students.
Post one-way announcements on the batch notice board.
Chat privately with students and parents using text and file attachments.
Upload and share notes, study materials, and other safe file types for each batch.
Record student progress by adding scores (subject, topic, marks obtained, maximum marks) and remarks.
View basic analytics such as attendance percentage, score trends, and recent progress remarks.
Configure and view in-app notifications for relevant events.

2.2 Student Requirements
Join a batch using an invite link.
Create an account using email and password.
View enrolled batches and their schedules.
View notice board announcements.
Access and download shared notes and study materials.
View personal attendance records.
View personal progress records, including scores and tutor remarks.
View basic analytics related to attendance and academic performance.
Chat privately with the tutor (not visible to the parent).
Receive and manage in-app notification preferences.

2.3 Parent Requirements
Join using an invite link.
Create an account using email and password.
Link multiple children (siblings) to a single parent account.
View a combined dashboard showing all subjects and batches for each child.
View each child's attendance records.
Access notes and study materials shared for each child.
View each child's progress reports and basic analytics.
Chat privately with the tutor.
Be restricted from viewing the child's private chat with the tutor.
Receive and manage in-app notification preferences.




3. Module Specification
Module 1: Authentication &amp; Onboarding
Email/password signup and login
Invite link generation (tutor-side), single-use, expiring
Role assignment (student/parent) tied to invite
Parent-to-child account linking
Forgot-password / reset-password flow
Session/token-based auth (JWT)
Module 2: Batch &amp; Subject Management
CRUD for subjects
CRUD for batches (name, subject, student list, recurring schedule)
Auto-generation of sessions from batch schedule
Holiday/no-class marking per batch/date
Schedule-change confirmation workflow
Student add/remove/deactivate per batch (archival on removal)
Module 3: Attendance
Session list per batch (auto-generated + holiday-aware)
Per-student attendance marking (present/absent)
Edit/delete previously marked attendance
Attendance data feeds Module 6 (analytics)
Module 4: Communication
Notice board: tutor-to-batch one-way broadcast (no replies)
Private chat: tutor ↔ parent (per parent)
Private chat: tutor ↔ student (per student, hidden from parent)
Text + file/image attachment support in private chats
Read/seen receipts
Real-time delivery (via WebSocket/Socket.io)
Module 5: Notes &amp; Resource Sharing
File upload (safe file types only — executable/script types blocked) per batch
Cloud storage integration (e.g., S3/Cloudinary) for file hosting
File listing/download per batch, accessible to enrolled students/parents
Module 6: Progress Tracking &amp; Light Analytics
Progress entry: structured (subject, topic, marks, max marks) + free-text remark, logged ad-hoc
Light analytics views: 
Attendance percentage per batch/student
Score-over-time simple table/graph per subject
Recent remarks feed
Data model designed to directly extend into v2 rich analytics (topic breakdowns, trend charts, engagement metrics) without restructuring
Module 7: Notifications
In-app notification center (bell/badge)
Event triggers: new message, attendance marked, new note shared, new progress entry
Per-user configurable notification preferences
Module 8: Parent Dashboard
Cross-batch, per-child aggregated view
Child-switcher for parents with multiple children
Surfaces attendance, notes, progress/analytics, and chat access per child
